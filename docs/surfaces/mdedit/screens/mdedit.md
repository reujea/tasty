## 트리거

- 마크다운 파일의 "다른 앱으로 열기" 목록에서 **마크다운 편집기**를 고른다.
- `mdedit` surface 를 `file` param 으로 만든다(`mode = "source"` 면 원문 모드로 연다). 생성 경로는 [../index.md](../index.md#생성갱신종료).

## UI 요소 인벤토리

- **툴바**(위쪽 고정) — `미리보기 | 원문` 전환 · `저장`(편집 버퍼가 base 와 다르거나 미리보기에 적용 전 고침이 있을 때만 활성 — `mdedit status` 의 dirty 와 같은 값) · 상태(`저장됨`/`수정됨`/`충돌`, 툴팁은 디스크 내용 hash) · 파일명(툴팁은 전체 경로) · `검토 N`(외부 변경이 있을 때만) · `스냅샷`.
- **배너**(툴바 아래, 하나) — 병합·저장 거부·경고 알림. 정보/경고/오류 색. `×` 로 닫는다.
- **패널**(배너 아래, 하나) — conflict(있으면 항상) · 검토 · 스냅샷 중 하나. 최대 높이 45vh, 넘치면 스크롤.
  - conflict: 곳마다 줄 번호 + 내 것/디스크 것 두 블록 + `내 것`·`디스크 것`·`둘 다` 선택, 위쪽 `적용`(전부 골랐을 때만 활성).
  - 검토: hunk 마다 출처 태그(에이전트/외부) + 줄 번호 + 지운 줄(빨강 배경)·더한 줄(초록 배경) + `유지`·`되돌리기`, 위쪽 `모두 유지`.
  - 스냅샷: 시각 · 사유 · 크기 + `복원`, 최신순.
- **원문 편집기**(원문 모드) — 줄 번호 거터 + 줄바꿈 없는 고정폭 편집 영역. 외부 변경 줄은 거터에 표시한다(에이전트 = 강조색, 외부 = 경고색). `Tab` 은 탭 문자를 넣는다. conflict 동안 읽기 전용.
- **미리보기**(미리보기 모드) — 뷰어와 같은 본문 · TOC · 찾기 바. 주소창은 숨긴다. 체크박스는 누를 수 있다(conflict 동안 비활성) — 누르면 상태가 `수정됨` 이 되고 파일에는 저장할 때 쓴다. 본문 바로 아래 제목과 하위 목록을 가진 항목은 왼쪽 여백에 접기 화살표(`▼` 펼침 · `▶` 접힘)가 있다 — 펼친 것은 가리킬 때만, 접힌 것은 늘 보인다. `> [!agent]` 블록은 왼쪽 강조선 + 옅은 배경 + `에이전트` 배지 · 시각 · 굵은 제목으로 그린다.
  - 편집할 수 있는 블록은 마우스를 올리면 점선 윤곽이 생기고 커서가 글자 커서다(목록 항목은 윤곽 없음). 누르면 그 블록이 렌더 모양 그대로 강조색 실선 윤곽을 두르고 누른 자리에 커서가 놓인다. 표 셀이면 셀 바로 아래에 `위에 행 추가`·`아래에 행 추가` 단추가 뜬다.
  - 원문과 맞추지 못한 블록은 그 자리에 강조색 테두리의 입력칸이 원문 조각을 담아 열리고, 아래에 작은 안내(`Enter: 적용 · Esc: 취소 · /: 블록 넣기`)가 붙는다. 그 자리 편집 중 Enter 는 커서 자리에서 블록을 나눠 새 항목·새 문단을 커서 머리로 연다.
  - 블록에 마우스를 올리면 왼쪽 여백에 `+` · `⠿` 손잡이가 뜬다(툴팁 `삽입` · `드래그하여 이동 · 클릭하여 메뉴`). `⠿` 를 끌면 끼울 자리에 강조색 가로선이 보이고, 누르면 그 블록에 옅은 배경이 깔리고 바로 아래에 블록 메뉴(`형식 변경` 머리 + 형식들 · 구분선 · `위로 이동` · `아래로 이동` · `복제` · 위험색 `삭제`, 쓸 수 없는 항목은 흐림)가 뜬다. 편집 중인 블록도 옅은 배경이고, 도구 막대 상태 옆에 `· 형식 이름` 이 붙는다.
  - `/` 메뉴는 입력칸(그 자리 편집이면 그 블록) 바로 아래에 뜨는 목록이고(아래 공간이 모자라고 위가 더 넓으면 입력칸 위로 편다), 고른 항목은 강조색 배경이다. 맞는 것이 없으면 `맞는 블록이 없습니다`.
  - 본문 끝에 점선 테두리의 `+ 줄 추가` 줄이 있다(올리면 강조색).

## 상태별 시각

- 파일을 못 읽으면 상태가 `파일을 읽지 못했습니다` 이고 본문 자리에 실패 문구가 뜬다.
- 모드 전환·conflict 시작·해결은 문서를 다시 싣는다 — 원문 편집기의 커서·선택·스크롤과 미리보기 스크롤은 파일별로 되살린다. 그 밖의 갱신(저장 결과·배너·패널·에이전트 쓰기 반영)은 문서를 다시 싣지 않는다. 미리보기 편집의 적용은 문서를 다시 싣는다(스크롤은 되살린다).
