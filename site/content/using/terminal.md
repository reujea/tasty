# 터미널 다루기

명령을 실행하면서 필요한 출력을 복사하고, 검색하고, 파일 경로를 열어보세요. 마우스 없이 선택하는 복사 모드와 작업 완료 알림도 사용할 수 있습니다.

아래 단축키는 기본 **Tasty** 프리셋 기준입니다. macOS에서는 `Alt`를 `Cmd`로 읽으면 됩니다.

## 셸

**설정** > **터미널** <!-- en: Terminal --> 에서 정합니다.

- **셸** <!-- en: Shell --> — 실행할 셸. Windows 는 Git for Windows 의 bash 를 찾고, 없으면 경로를 직접 지정하라고 알립니다.
- **시작 명령어** <!-- en: Startup command --> — 새 터미널마다 처음에 입력할 한 줄.
- **작업 디렉토리 상속** <!-- en: Inherit working directory --> — 새 터미널을 현재 터미널의 디렉터리에서 시작합니다(기본 켜짐).
- **실행 중 프로세스 닫기 확인** <!-- en: Confirm close running process --> — 프로그램이 돌고 있는 터미널을 닫을 때 확인합니다.

bash(4.4 이상)와 zsh 는 별도 설정 없이 셸 통합이 붙습니다. 탭 이름이 현재 디렉터리를 따라가고, 상태바에 git 브랜치가 뜨고, 명령이 끝났을 때 훅을 걸 수 있습니다([훅 · 알림](../agents/hooks-notifications.md)). fish 등 다른 셸은 직접 설정해야 하며, 그럴 때 **셸 통합이 감지되지 않았습니다** <!-- en: Shell integration not detected --> 배너가 뜰 수 있습니다. 원격 Tasty 에 attach 해서 보는 터미널에는 이 배너를 띄우지 않습니다. 이 배너는 10초 뒤 저절로 닫히며, 마우스를 올려 두면 닫히지 않고 기다립니다.

프로그램이 종료해 셸이 끝나면 그 서피스는 자동으로 닫힙니다.

## 방향키와 보조키

터미널 프로그램은 `Shift`·`Ctrl`·`Alt`와 함께 누른 방향키를 일반 방향키와 구분해 받습니다. **이 조합에서 macOS의 키는 `Cmd`가 아니라 실제 `Option`입니다.** 예를 들어 프로그램이 `⌥ + ↑`를 안내하면 `Option+↑`를 누릅니다. 동작은 터미널 안 프로그램이 정합니다.

방향키 조합은 **Option as Meta** 설정을 켜거나 꺼도 전달됩니다. 이 설정은 macOS의 Option+문자를 특수문자로 입력할지 Meta 키로 전달할지만 정합니다. Tasty 단축키로 등록된 조합이나 복사 모드·입력을 가로채는 오버레이가 소비하는 키는 프로그램으로 보내지 않습니다.

## 앱별 Shift+Enter 설정

**설정 → 터미널 → 입력**에서 실행 파일명(예: `claude`)을 추가하고 **Shift+Enter로 줄바꿈 문자 보내기**를 켜거나 끌 수 있습니다. 켜면 줄바꿈 문자(LF)를 보내고, 끄거나 규칙을 삭제하면 플랫폼 기본 키 전송 방식을 사용합니다. 변경한 뒤 설정을 저장하면 적용됩니다.

Claude Code 플러그인은 설치 후 처음 활성화될 때 `claude`의 줄바꿈 규칙을 자동으로 추가합니다. 이미 설치된 경우에도 업데이트 후 처음 활성화할 때 등록됩니다. 기존에 지정한 값과 이후 수정·삭제한 규칙은 유지합니다.

실행 파일명은 대소문자와 `.exe`를 제외하고 정확히 일치해야 합니다. 앱 전환 감지에는 최대 1초가 걸릴 수 있습니다. `node` 같은 런처만 감지되는 경우에는 해당 실행 파일명으로 규칙을 추가해야 합니다. 이 설정은 붙여넣기나 일반 Enter에는 적용되지 않습니다.

Windows용 Codex CLI는 기본 키 전송 방식에서 `Shift+Enter` 또는 `Ctrl+J`로 줄바꿈하고 `Enter`로 전송합니다.

## 복사 · 붙여넣기

| 하는 일 | 단축키 |
|---------|--------|
| 복사 | `Ctrl+C` · `Alt+C` · `Ctrl+Shift+C` |
| 붙여넣기 | `Ctrl+V` · `Alt+V` · `Ctrl+Shift+V` |
| 복사 모드 진입 | `Ctrl+Shift+Space` |

- `Ctrl+C` 는 선택 영역이 있으면 복사, 없으면 평소처럼 프로그램을 중단합니다.
- 붙여넣기 직후 0.5 초 안의 `Ctrl+C` 는 무시됩니다 — `Ctrl+V` 옆 키를 잘못 눌러 입력을 날리는 사고를 막습니다. 무시되면 토스트로 알립니다.
- 클립보드에 텍스트가 없고 이미지가 있으면 PNG 파일로 저장한 뒤 그 경로를 붙여넣습니다. 에이전트에게 스크린샷을 건넬 때 씁니다. 저장은 화면을 멈추지 않고 뒤에서 하며, 저장이 끝나면 붙여넣은 터미널에 경로가 들어갑니다. 그 사이에 친 글자는 경로보다 먼저 들어갈 수 있습니다. 그 사이 터미널을 닫으면 경로를 넣지 않고 파일을 지웁니다.
- 윈도우 폭 때문에 접힌 줄은 복사할 때 한 줄로 합쳐집니다.
- 우클릭 메뉴로 복사하면 "Copied" 알림 오른쪽에 복사 단축키가 함께 보입니다. 탐색기 우클릭 메뉴의 경로 복사도 경로 복사 단축키를 보여 줍니다. 단축키로 복사했거나 단축키를 비워 두었다면 보이지 않습니다.

### 스크린샷을 클립보드로

`Ctrl+Alt+S` 를 누르고 화면 영역을 고르면 PNG 파일을 `~/.tasty/screenshots/` 에 저장하고 클립보드에 그 경로와 이미지를 함께 넣습니다. 터미널에 붙여넣으면 경로가, 이미지 편집기처럼 그림을 받는 앱에 붙여넣으면 이미지가 들어갑니다. 원격 mirror 워크스페이스에서 누르면 파일은 원격 컴퓨터에 저장되고 원격 클립보드에 들어갑니다.

- **macOS**: `screencapture` 로 영역을 고릅니다. 화면 기록 권한이 필요합니다.
- **Linux**: Wayland 에서는 `grim`·`slurp`, 없으면 `gnome-screenshot` 을 씁니다. X11 에서는 `gnome-screenshot` → `scrot` → ImageMagick `import` 순서로 설치된 도구를 씁니다. 한 도구가 실패하면 다음 도구로 넘어갑니다.
- **Windows**: 영역 선택 없이 모든 모니터를 합친 화면 전체를 캡처합니다.
- 이미지를 클립보드에 넣지 못하면(그림을 읽지 못함, Linux 에서 그림이 X11 한 번의 전송 한도보다 큼 등) 경로만 넣습니다.
- 영역 선택을 Esc 로 취소하면 다른 도구를 다시 열지 않고 클립보드도 그대로 둡니다. 도구가 파일을 남기지 않고 끝난 경우도 같습니다.
- 결과는 단축키를 누른 윈도우에 알림으로 뜹니다. 이미지와 경로를 모두 넣으면 성공, 경로만 넣었으면 경고, 도구가 없거나 실패했거나 저장·복사를 못 했으면 그 이유를 알립니다. Esc 로 취소하면 알림이 없고, 도구가 파일 없이 끝나면(일부 도구는 취소해도 이렇게 끝납니다) "스크린샷을 찍지 않았습니다" 라고만 알립니다. 영역을 고르는 동안 다른 윈도우로 옮겨도 알림은 처음 윈도우에 뜨며, 그 윈도우를 닫았다면 뜨지 않습니다.

### 선택

드래그(문자) · 더블클릭(단어) · 트리플클릭(줄). 선택은 스크롤백까지 이어집니다. 선택 후 우클릭하면 **복사** <!-- en: Copy --> · **줄바꿈 없이 복사** <!-- en: Copy Without Line Breaks --> · **터미널 ID 복사** <!-- en: Copy Terminal ID --> 메뉴가 뜹니다. 선택한 글자가 실제 파일 · 폴더 경로면 **파일 열기** <!-- en: Open File --> / **폴더 열기** <!-- en: Open Folder --> 도 나타납니다.

셸에서 명령을 입력하는 중에 입력 줄을 한 번 클릭하면 커서가 그 위치로 옮겨집니다. 셸이 아닌 프로그램, 스크롤백을 올려 본 상태, 마우스를 잡는 프로그램에서는 옮기지 않습니다. 이 동작을 끄려면 `config.toml`의 `[general]`에 `click_to_move_cursor = false`를 넣습니다([설정](../customize/settings.md)).

### 복사 모드 (vi)

마우스 없이 화면과 스크롤백을 돌아다니며 복사합니다. 터미널을 클릭한 뒤 `Ctrl+Shift+Space` 로 들어갑니다. macOS 에서도 `Cmd` 가 아니라 `Control` 키입니다. 단축키를 바꿨다면 바꾼 키를 누릅니다.

들어가면 터미널 오른쪽 아래에 이동 · 선택 · 복사 · 종료 키를 알려 주는 알림이 뜨고, 현재 화면 첫 줄의 첫 칸에 복사용 커서가 생깁니다. 복사 모드에서 누른 키는 셸이나 프로그램으로 보내지 않습니다.

들어가지 못하면 그 이유를 알림으로 알려 줍니다.

- vim · less 처럼 터미널의 **대체 화면**을 쓰는 프로그램이 떠 있는 동안은 들어갈 수 없습니다. 윈도우를 최대화하거나 OS 전체 화면으로 바꾼 것과는 상관없습니다. 프로그램을 나간 뒤 다시 시도합니다.
- 탐색기처럼 터미널이 아닌 서피스에서는 들어갈 수 없습니다. 마크다운 · HTML 서피스가 키 입력을 받고 있을 때도 들어갈 수 없지만, 이때는 이유 알림이 그 서피스 화면에 가려 보이지 않을 수 있습니다.
- 이미 복사 모드라면 다시 들어가지 않고 그 사실을 알려 줍니다.

모달이나 팝업이 키보드 입력을 받고 있으면 단축키가 그쪽으로 가므로 복사 모드도 알림도 나타나지 않습니다. 터미널을 클릭한 뒤 다시 누릅니다.

예를 들어 셸에서 `printf '\033[2J\033[HABCDE\n'` 를 실행하면 화면 맨 위에 `ABCDE` 가 남습니다. 복사 모드에 들어가 `A` 위의 커서를 확인한 뒤 `Ctrl` · `Shift` 를 떼고 `v` `l` `l` `y` 를 차례로 누르면 `ABC` 가 클립보드에 복사되고 복사 모드가 끝납니다.

| 키 | 동작 |
|----|------|
| `h` `j` `k` `l` | 이동. 앞에 숫자를 붙이면 반복 |
| `w` `b` `e` / `W` `B` `E` | 단어 단위 이동 |
| `0` `^` `$` | 줄 처음 / 첫 글자 / 줄 끝 |
| `gg` `G` / `H` `M` `L` | 맨 위 / 맨 아래 / 화면 위 · 가운데 · 아래 |
| `v` / `V` | 문자 / 줄 선택 시작 |
| `y` | 복사에 성공하면 나갑니다. 실패하면 선택을 유지합니다. 선택 없이 누르면 복사하지 않고 나갑니다 |
| `/` `?` `n` `N` | 아래 · 위로 검색, 다음 · 이전 결과 |
| `"+` `"*` | 다음 복사의 대상 클립보드 지정 |
| `q<문자>` … `q` / `@<문자>` | 매크로 녹화 / 재생 |
| `Esc` | 선택 해제. 선택이 없으면 나갑니다. 선택 중이라면 첫 `Esc` 로 선택을 풀고 두 번째 `Esc` 로 나갑니다 |

클립보드 쓰기가 성공했을 때만 복사 알림이 나타납니다. 접근할 수 없거나 전송에 실패하면 안내를 표시하고 선택을 유지합니다. 선택이 있을 때 Ctrl+C 복사에 실패해도 프로그램을 중단하지 않습니다. 붙여넣기에 실패하면 입력을 보내지 않으며, 클립보드가 비어 있으면 아무 동작도 하지 않습니다.

Linux의 터미널 복사·붙여넣기는 X11을 사용하며 Wayland 세션에서는 XWayland를 거칩니다. 네이티브 Wayland 클립보드는 지원하지 않습니다. X11 클립보드에 접근할 수 없으면 그 사실을 알려 줍니다.

### 프로그램의 클립보드 접근 (OSC 52)

터미널 안 프로그램(tmux, 원격 vim 등)이 클립보드에 **쓰기**를 요청할 수 있습니다. 쓰기가 성공한 뒤에만 복사 알림을 표시하며, 접근 불가나 실패도 알려 줍니다. **읽는** 것은 **설정** > **터미널** > **클립보드 읽기 허용 (OSC 52)** <!-- en: Allow clipboard read (OSC 52) --> 을 켜야 합니다. 기본은 꺼짐이며, 켜면 SSH 너머의 프로그램도 클립보드 내용을 가져갈 수 있으니 주의합니다.

### 스크립트에서 클립보드에 쓰기

스크립트나 에이전트가 클립보드에 텍스트를 직접 넣을 수 있습니다.

```sh
tasty clipboard set-text "복사해 둘 내용"
```

## 검색

`Ctrl+F` 또는 `Alt+F`, 또는 탭 스트립의 검색 아이콘. 서피스 위쪽 가운데에 검색 바가 뜹니다.

일반 터미널에서는 스크롤백과 화면 전체를 검색합니다. vim·less처럼 대체 화면을 쓰는 프로그램 안에서는 현재 화면만 검색합니다. 이전 셸의 기록은 프로그램을 나간 뒤 검색할 수 있습니다.

- `Enter` / `Shift+Enter` / `↑` `↓` — 다음 / 이전 결과. 결과 수가 `3/42` 로 보이고 화면이 따라갑니다.
- 결과는 옅은 노란색, 지금 결과는 진한 노란색으로 칠합니다. 지금 결과 안의 글자는 프로그램이 정한 색과 관계없이 테마의 강조 글자색으로 그려 어느 테마에서도 읽힙니다. 나머지 결과는 원래 글자색을 유지합니다.
- 오른쪽 토글 — **대소문자 구분** <!-- en: Match case --> · **정규식** <!-- en: Regular expression --> · **단어 단위 일치** <!-- en: Match whole word -->.
- 검색 바에 커서가 있을 때 `Esc` 또는 `×` — 닫기. 검색 바가 떠 있어도 터미널에 커서가 있으면 키 입력은 그대로 터미널로 갑니다. `Ctrl+F` 를 다시 누르면 검색 바와 터미널 사이를 오갑니다.
- 검색어 칸은 포커스가 없어도 배경과 테두리로 구분됩니다. 잘못된 정규식을 입력하면 칸의 테두리가 빨갛게 표시되고, 커서를 터미널로 옮겨도 오류 표시가 남습니다.
- 검색 바는 지금 커서가 있는 서피스에 뜹니다. 다른 탭이나 옆 분할 서피스에 검색 바가 열려 있으면 그 검색을 지우고 지금 서피스로 옮겨 옵니다.

## 링크와 경로 열기

`Ctrl` 을 누른 채 URL 이나 경로에 마우스를 올리면 파란 밑줄이 생기고, 클릭하면 브라우저 또는 연결된 프로그램으로 엽니다. 브라우저나 연결된 프로그램을 실행하지 못하면 그 터미널 오른쪽 아래에 열지 못했다는 알림이 뜹니다. 경로는 `src/main.rs` 같은 상대 경로도 되지만 현재 디렉터리 기준으로 실제 있는 것만 링크가 됩니다.

밑줄이 생긴 링크 위에서 우클릭하면 링크 전용 메뉴가 뜹니다.

- **선택** <!-- en: Select --> — 링크 텍스트 전체를 선택합니다.
- **복사** <!-- en: Copy --> — 화면에 보이는 링크 텍스트를 복사합니다. 단축키 설정에서 **링크 복사** 에 키를 지정해 두면 "Copied" 알림 오른쪽에 그 키가 보이고, 링크 위에서 그 키를 누르면 메뉴 없이 복사합니다. 기본 키는 없습니다.
- **열기 방법 선택…** <!-- en: Open With… --> — 바로 열지 않고 어떤 프로그램으로 열지 고르는 목록을 띄웁니다. `http(s)://` 주소도 고를 수 있어, 예를 들어 HTML 뷰어를 고르면 브라우저 대신 Tasty 안의 탭으로 엽니다. 원격 attach 한 터미널의 경로는 이 컴퓨터에서 열 수 없어 빈 목록만 뜹니다.

마우스를 쓰는 프로그램(vim · tmux 등)이 돌고 있어도 링크 위 우클릭은 그 프로그램으로 가지 않고 이 메뉴가 뜹니다. 링크가 아닌 곳의 우클릭은 이전과 같습니다.

**설정** > **터미널** > **링크 클릭 수식키** <!-- en: Link click modifier --> 에서 `Ctrl` · `Alt` · **좌클릭 열기 끄기** <!-- en: Disable left-click opening --> 중 고릅니다. **좌클릭 열기 끄기**를 선택하면 좌클릭으로 링크를 열지 않습니다. 수식키 없이 링크에 마우스를 올려 표시할 수 있으며, 링크 위 우클릭 메뉴는 계속 사용할 수 있습니다. 팝업이나 배너 위에서는 링크 표시가 차단될 수 있습니다.

파일이 열리는 방식(마크다운 · 이미지 · 탐색기)은 [파일 관리와 보기](files.md). 파일을 터미널 위로 드래그해 놓으면(**여기에 드롭하여 열기** <!-- en: Drop to open -->) 같은 규칙으로 열립니다.

## 스크롤

- 마우스 휠, 또는 `PageUp` / `PageDown` (한 화면씩) 으로 스크롤백을 봅니다. 타이핑하면 맨 아래로 돌아옵니다.
- vim · less · htop 처럼 화면 전체를 쓰는 프로그램 안에서는 휠과 `PageUp` / `PageDown` 이 프로그램으로 전달됩니다.
- 보관 줄 수는 **설정** > **터미널** > **스크롤백 줄 수** <!-- en: Scrollback lines --> (기본 10,000, 최대 100,000). `clear` 는 스크롤백도 비웁니다.
- 재시작 후에도 스크롤백이 이어집니다 — [워크스페이스](workspaces.md#재시작-후-복원).

글자 크기는 `Ctrl+=` / `Ctrl+-` 로 키우고 줄이며 `Ctrl+0` 으로 되돌립니다. 포커스된 서피스에 적용되며, 터미널 · 탐색기 · 마크다운이 대상입니다.

## 마우스를 잡는 프로그램

vim(`:set mouse=a`) · htop · Claude Code 처럼 마우스를 직접 쓰는 프로그램이 뜨면 클릭과 드래그가 그 프로그램으로 넘어갑니다. 처음 클릭할 때 배너가 뜹니다.

> **마우스 입력 캡처 중** <!-- en: Mouse input captured --> — 이 앱이 마우스를 캡처하고 있습니다. 텍스트 선택은 Shift+드래그, tasty 메뉴는 Shift+우클릭을 사용하세요.

- `Shift+드래그` — 텍스트 선택. `Shift+더블클릭` 은 단어.
- `Shift+우클릭` — Tasty 의 복사 메뉴.
- 배너는 프로그램이 끝나면 저절로 닫힙니다. `×` 로 바로 닫아도 됩니다.
- 배너에 마우스를 올리면 나오는 **더 보기** <!-- en: More options --> 에서 **{프로그램}에서 다시 보지 않기** 또는 **{프로그램}에서 클릭은 Tasty가 처리** 를 고릅니다. 클릭을 Tasty가 처리하면 그 프로그램 위에서는 클릭이 평소처럼 선택으로 동작하고 휠만 프로그램으로 갑니다. 원격 Tasty 에 attach 해서 보는 터미널처럼 실행 중인 프로그램을 확인할 수 없을 때는 두 항목이 흐리게 보이고 고를 수 없습니다. 메뉴 위쪽 안내가 그 이유를 알려 줍니다.

같은 항목은 **설정** > **터미널** > **마우스 캡처** <!-- en: Mouse Capture --> 에 있습니다 — **마우스 캡처 안내 표시** <!-- en: Show mouse-capture hint --> 토글, **클릭을 Tasty가 처리할 프로그램** <!-- en: Let Tasty handle clicks in these programs --> 목록, **캡처 안내를 다시 보지 않을 프로그램** <!-- en: Don't show the capture notice for these programs --> 목록. 이름은 부분 일치이고 `ht*` 같은 와일드카드를 씁니다.

## 실행 중 · 확인 필요 표시

- 탭의 **녹색 점**, 사이드바 카드의 점 — 셸이 아닌 프로그램이 출력을 내는 중. 입력을 기다리며 멈춰 있으면 사라집니다. 터미널 제목만 바꾸는 출력은 출력으로 치지 않습니다.
- 서피스의 **노란 테두리** — 프로그램이 응답을 기다립니다(에이전트가 질문한 경우). **파란 테두리** — 명령이 끝났거나 알림이 왔습니다. 그 서피스를 클릭하면 사라집니다. 탭 이름과 사이드바 배지도 같은 색을 씁니다.

## 알림

터미널 벨(`\a`)과 프로그램이 보내는 알림 시퀀스(OSC 9 · 99 · 777)를 모아 보여줍니다.

- `Ctrl+Shift+I` — **알림** <!-- en: Notifications --> 패널. 최신순 목록과 **이동** <!-- en: Jump --> 버튼, **모두 읽음** <!-- en: Mark all read -->. 열면 전부 읽음 처리됩니다. 타이틀바의 전체화면 버튼으로 크게 볼 수 있습니다([전체화면](panes-tabs-splits.md#전체화면)).
- OS 알림 센터로는 보내지 않습니다. 윈도우가 뒤에 있어도 알림은 이 패널과 서피스 테두리, 사이드바 배지로 확인합니다.
- **설정** > **일반** > **알림** <!-- en: Notifications --> — **알림 활성화** <!-- en: Notifications enabled --> · **소리** <!-- en: Sound --> · **알림 병합 간격 (ms)** <!-- en: Coalesce interval (ms) --> (같은 곳에서 연달아 온 알림을 하나로 합치는 간격, 기본 500).
- 벨만 끄려면 **설정** > **터미널** > **벨 알림 표시** <!-- en: Show bell notification -->.

스크립트에서 직접 알림을 띄우려면 `tasty notify "빌드 끝" --title build`.

## 플랫폼별 참고

- **macOS** — **설정** > **터미널** > **Option 을 Meta 로 사용** <!-- en: Use Option as Meta --> 을 켜면 `Option+F` 같은 조합이 특수문자 대신 readline · Emacs 의 Meta 키로 들어갑니다(기본 꺼짐).
- **Windows** — 절전에서 깨어난 뒤 터미널이 응답하지 않을 수 있습니다. Tasty 가 깨우기를 시도하고, 그래도 멈춘 것으로 보이면 알림으로 알립니다. 그때는 그 터미널을 새로 엽니다.
- 화면 전체가 번쩍이는 프로그램(readline 의 visible bell 등)이 거슬리면 **설정** > **터미널** > **화면 반전 플래시 (DECSCNM)** <!-- en: Reverse-screen flash (DECSCNM) --> 을 끕니다.
