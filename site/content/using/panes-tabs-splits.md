# 페인 · 탭 · 분할

페인은 탭을 따로 전환할 영역을 만들고, 서피스 분할은 한 탭에서 함께 볼 화면을 나눕니다. 원하는 배치에 따라 두 분할을 골라 사용하세요.

아래 단축키는 기본 **Tasty** 프리셋 기준입니다. macOS에서는 `Alt`를 `Cmd`, `Ctrl`을 `Control`로 읽으면 됩니다.

## 두 단계 분할 — 먼저 고르기

| | 페인 분할 | 서피스 분할 |
|--|-----------|-------------|
| 나누는 것 | 워크스페이스 | 탭 하나의 안쪽 |
| 탭을 바꾸면 | 다른 페인은 그대로 | 분할 전체가 함께 바뀝니다 |
| 탭 스트립 | 페인마다 따로 | 탭 하나가 공유 |
| 좌우 / 상하 | `Alt+E` / `Alt+Shift+E` | `Alt+D` / `Alt+Shift+D` |
| 다음 / 이전 포커스 | `Ctrl+]` / `Ctrl+[` | `Alt+]` / `Alt+[` |
| 닫기 | `Ctrl+Shift+W` | `Alt+W` |

- 에이전트 화면을 한쪽에 열어두고 다른 쪽의 탭을 바꿔가며 작업하려면 **페인 분할**을 사용하세요.
- 같은 작업의 로그와 에디터를 나란히 두고 함께 전환하려면 **서피스 분할**을 사용하세요.

새 칸의 터미널은 원래 칸의 작업 디렉터리에서 시작합니다(**설정** > **터미널** > **작업 디렉토리 상속**). 칸 사이 경계를 드래그하면 비율이 바뀝니다.

탭 스트립 오른쪽의 분할 아이콘은 그 페인을 좌우로 나눕니다. 다른 종류의 서피스로 나누려면 CLI 를 씁니다.

```sh
tasty split --level pane --pane 1 --direction horizontal
tasty split --level surface --surface 5 --type markdown --file notes.md
tasty split --level surface --surface 5 --type explorer --path ~/proj
```

## 탭

### 만들기 · 닫기

- `+` 버튼 또는 `Alt+T` — 새 터미널 탭.
- `+` 우클릭 — **프리셋으로 탭 생성...** <!-- en: Create tab from preset... --> / **프리셋으로 페인 생성...** <!-- en: Create pane from preset... -->.
- 탭 스트립 빈 곳 우클릭 — **새 터미널** <!-- en: New Terminal --> · **새 마크다운...** <!-- en: New Markdown... --> · **새 HTML...** <!-- en: New HTML... --> · **새 이미지** <!-- en: New Image --> 로 새 탭을 만듭니다. **새 HTML...** 은 파일 선택 창에서 HTML · SVG 파일을 고르면 그 페인에 탭을 엽니다. 같은 메뉴에 **페인 프리셋으로 저장** <!-- en: Save as pane preset -->, **프리셋으로 탭 생성...** <!-- en: Create tab from preset... -->, **프리셋으로 페인 생성...** <!-- en: Create pane from preset... --> 도 있습니다. 종류별 설명은 [파일 관리와 보기](files.md).
- 탭의 `×`, 탭 우클릭 > **탭 닫기** <!-- en: Close Tab -->, 또는 `Ctrl+W`. 페인의 마지막 남은 탭은 닫히지 않습니다. 페인째 닫으려면 페인 닫기(`Ctrl+Shift+W`)를 사용하세요.

```sh
tasty list panes
tasty new tab --pane 1 --cwd ~/proj
tasty new tab --pane 1 --type html --url https://example.com
tasty list tabs --pane 1
tasty close tab --tab 7
```

### 전환 · 순서

- 클릭, 또는 `Ctrl+1` ~ `Ctrl+9`, `Ctrl+0` (10 번째). `Ctrl` 을 누르고 있으면 탭에 번호가 뜹니다.
- `Ctrl+L` / `Ctrl+H` — 다음 / 이전 탭. **다음 탭** <!-- en: Next tab --> / **이전 탭** <!-- en: Previous tab --> 단축키는 OS 와 겹치지 않도록 기본값이 비어 있습니다.
- 드래그로 순서를 바꿉니다. 탭 우클릭 > **왼쪽으로 이동** <!-- en: Move Left --> / **오른쪽으로 이동** <!-- en: Move Right --> 도 됩니다.
- 탭이 넘치면 좌우 화살표가 생깁니다. 단축키로 전환하면 활성 탭이 보이도록 자동 스크롤합니다.

### 이름과 표시

탭 이름은 우선순위대로 정해집니다 — 직접 지정한 이름 > 프로그램이 설정한 윈도우 제목 > 셸의 현재 디렉터리.

- 탭 우클릭 > **탭 이름 변경** <!-- en: Rename Tab --> 또는 `F2`. 지정하면 디렉터리를 옮겨도 바뀌지 않습니다.
- **녹색 점** — 셸이 아닌 프로그램이 출력을 내는 중. 프롬프트 대기 중이거나 프로그램이 멈춰 있으면 사라집니다. 터미널 제목만 바꾸는 출력은 세지 않으므로, 입력을 기다리며 제목만 깜빡이는 프로그램(예: Codex 의 질문 대기)에서도 사라집니다.
- **노란 이름** — 프로그램이 입력을 기다립니다. **파란 이름** — 작업이 끝났습니다. 그 서피스를 클릭하면 원래 색으로 돌아옵니다.

탭 폭과 글자 크기는 설정 윈도우에 항목이 없고 `~/.tasty/config.toml` 의 `[appearance]` 아래 `tab_width` · `tab_font_size` 로 바꿉니다.

### 재시작 후 보이지 않는 탭

레이아웃을 복원할 때 화면에 보이지 않는 탭의 셸은 바로 띄우지 않고 그 탭을 처음 열 때 시작합니다. `tasty list surfaces` 에는 `pty_ready: false` 로 나타나며, 열지 않고 미리 띄우려면 `tasty wake --surface <ID>`.

## 서피스 옮기기

사용 중인 서피스를 다른 탭, 페인, 워크스페이스로 옮길 수 있습니다. 터미널이면 실행 중인 프로그램과 스크롤백이 그대로 따라갑니다.

1. 옮길 서피스의 빈 곳을 우클릭 > **서피스 이동** <!-- en: Move Surface -->. 서피스를 잘라냈다는 알림이 그 서피스 위에 잠깐 뜹니다.
2. 목적지 서피스의 빈 곳을 우클릭 > **서피스를 이곳으로 이동** <!-- en: Move Surface Here -->. 이 항목은 서피스를 잘라 둔 동안에만 보입니다.

잘라 둔 것은 하나만 기억합니다. 다른 것을 다시 잘라내면 앞의 것은 잊습니다.

목적지 서피스는 닫히고 옮겨온 서피스가 그 자리를 차지합니다. 빈 터미널을 먼저 만들어 목적지로 삼으면 됩니다. 마우스를 잡는 프로그램(vim 등) 위에서는 `Shift+우클릭`.

## 탭 옮기기

탭 하나를 안의 분할과 함께 다른 페인이나 워크스페이스로 옮깁니다. 터미널의 실행 중인 프로그램과 스크롤백이 그대로 따라갑니다.

1. 옮길 탭을 우클릭 > **탭 이동** <!-- en: Move Tab -->. 탭을 잘라냈다는 알림이 그 페인 위에 잠깐 뜹니다.
2. 목적지 탭을 우클릭 > **탭을 이곳으로 이동** <!-- en: Move Tab Here -->. 이 항목은 다른 탭을 잘라 둔 동안에만 보입니다.

목적지 탭은 안의 서피스와 함께 닫히고 옮겨온 탭이 그 자리를 차지합니다. 옮긴 탭이 원래 페인의 마지막 탭이었다면 그 페인이 닫히고, 워크스페이스의 마지막 페인이었다면 워크스페이스가 닫힙니다. 원격 워크스페이스(attach 로 연결한 곳)의 탭은 옮길 수 없습니다. 잘라 둔 것은 같은 윈도우 안에서만 옮길 수 있습니다.

## 페인 옮기기

페인 하나를 안의 모든 탭과 함께 다른 분할 위치나 다른 워크스페이스로 옮깁니다. 터미널의 실행 중인 프로그램과 스크롤백이 그대로 따라갑니다.

1. 옮길 페인의 아무 탭이나 우클릭 > **페인 이동** <!-- en: Move Pane -->. 페인을 잘라냈다는 알림이 그 페인 위에 잠깐 뜹니다.
2. 목적지 페인의 탭을 우클릭 > **페인을 이곳으로 이동** <!-- en: Move Pane Here -->. 이 항목은 다른 페인을 잘라 둔 동안에만 보입니다.

목적지 페인은 안의 탭과 함께 닫히고, 옮겨온 페인이 그 자리를 같은 크기로 차지합니다. 원래 자리는 옆 페인이 넓어져 채웁니다. 옮긴 페인이 워크스페이스의 마지막 페인이었다면 그 워크스페이스가 닫힙니다. 원격 워크스페이스의 페인은 옮길 수 없고, 같은 윈도우 안에서만 옮길 수 있습니다.

## 잘라 둔 것 알아보기

잘라 둔 서피스·탭·페인은 안쪽에 분홍색 점선 테두리가 생깁니다. 서피스는 그 서피스 칸, 탭은 탭 제목 칸, 페인은 탭 줄까지 포함한 페인 전체를 두릅니다. 다른 테두리는 모두 실선이라 점선으로 구별됩니다. 알림 테두리가 있는 서피스라면 점선 사이로 원래 테두리가 보입니다.

잘라 둔 것이 지금 화면에 없으면 그것을 담은 곳에 이동 아이콘이 뜹니다.

- 보이지 않는 탭 안에 있으면 그 탭 제목 뒤.
- 다른 워크스페이스에 있으면 사이드바의 그 워크스페이스 줄. 사이드바를 접었다면 아바타 왼쪽 아래.

탭이 많아 탭 줄이 옆으로 밀려 있을 때 잘라 둔 탭, 또는 잘라 둔 서피스를 담은 탭(그 탭이 활성 탭이 아닐 때)이 탭 줄 밖에 있으면, 그 탭이 있는 쪽의 탭 줄 화살표가 분홍색으로 바뀝니다. 잘라 둔 서피스가 활성 탭 안에 있으면 서피스 테두리가 이미 화면에 보이므로 화살표는 바뀌지 않습니다. 탭이 탭 줄 안에 완전히 들어오면 화살표는 원래 색으로 돌아가고 탭의 표시가 보입니다. 분홍 화살표를 눌러도 평소처럼 한 칸씩만 밀립니다.

표시는 옮기기를 마치거나, 다른 것을 잘라내거나, 잘라 둔 것을 닫으면 사라집니다. 다른 탭이나 워크스페이스로 가도 남아 있으며 클릭을 막지 않습니다.

## 종류 바꾸기

`Alt+'` 를 누르면 **서피스 타입 전환** <!-- en: Surface Type --> 팝업이 뜹니다. 현재 서피스를 그 자리에서 **터미널** <!-- en: Terminal --> · **탐색기** <!-- en: Explorer --> · **마크다운** <!-- en: Markdown --> · **HTML...** · **이미지** <!-- en: Image --> · **DAG** 로 바꿉니다. 방향키와 `Enter`, 또는 행 오른쪽에 보이는 글자로 고릅니다. 글자가 없는 행은 방향키나 클릭으로 고릅니다. 지금 종류는 목록에 나오지 않습니다. 빈 서피스 가운데의 버튼도 같은 팝업입니다.

- 탐색기로 바꾸면 터미널의 현재 디렉터리를 루트로 엽니다.
- 마크다운 · HTML 은 파일 경로 · URL 을 묻습니다.
- 이전 내용은 사라집니다. 터미널 → 탐색기 → 터미널로 되돌려도 셸 세션은 새로 시작합니다.
- 팝업이 떠 있는 동안 어두워지는 것은 **그 서피스 한 칸**뿐입니다. 옆 칸에서 돌아가는 작업, 사이드바, 상태 표시줄은 그대로 보입니다.

**마크다운으로 전환** <!-- en: Convert to Markdown --> · **탐색기로 전환** <!-- en: Convert to Explorer --> 은 팝업 없이 바로 바꾸는 단축키로, 기본값이 비어 있습니다.

## 전체화면

알림 창 타이틀바의 전체화면 버튼(툴팁 **전체화면으로 보기** <!-- en: Show fullscreen -->)을 누르면 Tasty 윈도우가 모니터를 덮고 알림 목록만 크게 보입니다. `Esc` 또는 오른쪽 위 종료 버튼으로 나옵니다. 나오면 윈도우 크기와 터미널 격자가 진입 전 그대로입니다. 현재 전체화면 보기는 알림 목록에서 사용할 수 있습니다.

## 레이아웃 저장 — 프리셋

자주 쓰는 배치를 프리셋으로 저장해 두고 새 워크스페이스 · 탭 · 페인을 만들 때 꺼내 씁니다. 저장되는 것은 분할 구조와 각 칸의 종류 · 작업 디렉터리 · 시작 명령어 · 파일 경로 · URL 입니다.

프리셋은 배치와 시작 설정을 새 작업에 적용합니다. 실행 중인 프로세스를 복제하지 않습니다. 이전 작업의 배치와 기록을 되살리는 방법은 [워크스페이스의 복원 안내](workspaces.md#재시작-후-복원)를 참고하세요.

### 저장

- 워크스페이스 — 사이드바 카드 우클릭 > **워크스페이스 프리셋으로 저장** <!-- en: Save as workspace preset -->.
- 탭 — 탭 우클릭 > **탭 프리셋으로 저장** <!-- en: Save as tab preset -->.
- 페인 — 탭 스트립 빈 곳 우클릭 > **페인 프리셋으로 저장** <!-- en: Save as pane preset -->.

파일은 `~/.tasty/presets/{workspace,tab,pane}/<이름>.toml` 에 생깁니다. 같은 이름이 있으면 `-2` 처럼 뒤에 번호가 붙습니다.

불러온 뒤 다른 편집기에서 바뀐 파일이나 손상되어 읽지 못한 파일은 저장으로 덮어쓰지 않고 오류를 알립니다. 외부 변경 내용을 확인한 뒤 앱을 다시 열어 불러오세요.

이름 변경 중 새 파일을 저장한 뒤 이전 파일을 지우지 못하면 오류가 나고 두 이름이 함께 남을 수 있습니다. 목록과 파일을 확인한 뒤 남길 이름을 정하세요.

프리셋을 저장하거나 이름을 바꾸고 삭제하는 동안에는 편집기 입력이 잠시 비활성화됩니다. 파일 처리가 끝난 뒤 다시 편집할 수 있습니다. 저장 실패 시 오류를 알리고 편집 중이던 설정과 선택을 유지합니다. 여러 변경 중 일부만 저장됐다면 이미 저장된 변경은 남습니다.

### 편집

사이드바 **도구** <!-- en: Tools --> > **프리셋** <!-- en: Presets --> 을 열면 **레이아웃 프리셋** <!-- en: Layout Presets --> 윈도우가 뜹니다.

- 위쪽 탭으로 **워크스페이스** / **탭** / **페인** 을 고르고, 왼쪽 목록에서 프리셋을 고릅니다.
- 오른쪽에 구조 미리보기가 보입니다. 툴바의 **이름 변경** <!-- en: Rename --> · **복제** <!-- en: Duplicate --> · **삭제** <!-- en: Delete -->.
- **편집** <!-- en: Edit --> 을 누르면 미리보기 위에서 구조를 직접 고칩니다 — 칸 가장자리에 마우스를 올려 나타나는 띠를 클릭해 그쪽으로 나누고, 칸 가운데를 클릭해 고른 뒤 오른쪽 위 휴지통 핸들로 지우고, `+` / `×` 로 탭을 더하고 뺍니다. 고른 칸에는 본체와 같은 분할 · 닫기 단축키도 동작합니다.
- 구조를 바꾸면 저장 버튼 없이 자동으로 저장을 요청합니다. **자동 저장** <!-- en: automatic saving --> 은 이 저장 방식을 알려주는 안내입니다. **완료** <!-- en: Done --> 로 나옵니다.
- 칸의 종류 · 작업 디렉터리 · 시작 명령어는 **서피스 설정** <!-- en: Surface settings --> 화면에서 바꿉니다. 고른 칸의 톱니 핸들을 누르거나 칸을 더블클릭하면 오른쪽 영역 전체가 그 칸의 설정 화면이 됩니다. 칸이 아무리 작아도 모든 입력칸이 보입니다.
  - 값을 바꾸면 위쪽에 **저장 안 됨** <!-- en: unsaved --> 이 뜨고, 아래 **확인** <!-- en: OK --> 을 눌러야 저장됩니다. **취소** <!-- en: Cancel --> 또는 `Esc` 는 바꾼 값을 버립니다. 입력칸에서 `Enter` 를 눌러도 확인됩니다.
  - 설정 화면이 열려 있는 동안 왼쪽 목록과 위쪽 탭은 흐려지고 눌리지 않습니다. 확인이나 취소를 하면 미리보기로 돌아오고, 그 칸은 골라진 채로 남습니다.
- **새 프리셋** <!-- en: New preset --> 은 터미널 하나짜리 빈 프리셋을 만듭니다.

### 적용

- **새 워크스페이스** 버튼 우클릭 > **프리셋으로 새 워크스페이스 생성...** <!-- en: Create workspace from preset... -->.
- 탭 스트립 `+` 우클릭 > **프리셋으로 탭 생성...** / **프리셋으로 페인 생성...**.
- **워크스페이스 프리셋 적용** <!-- en: Apply workspace preset --> 등 단축키 세 개는 기본값이 비어 있습니다. 지정하면 선택 팝업이 뜹니다.

터미널 칸에 시작 명령어가 있으면 셸이 뜨자마자 한 줄 입력됩니다.

```sh
tasty preset list --kind workspace
tasty preset capture --kind workspace --source-id 2 --name dev
tasty preset apply --kind workspace --name dev
tasty preset apply --kind tab --name logs --target-pane 1
```

CLI 로 적용하면 포커스는 움직이지 않습니다. 재시작 시 자동 복원과 닫은 항목 복원은 [워크스페이스](workspaces.md#재시작-후-복원)에 있습니다.
