# 단축키

익숙한 단축키로 Tasty를 사용해 보세요. 프리셋을 고르거나 자주 쓰는 동작에 원하는 키를 지정할 수 있습니다. 단축키 설정은 **설정** <!-- en: Settings --> > **단축키** <!-- en: Keybindings --> 에서 찾을 수 있습니다.

## 표기 규칙

Tasty 는 단축키를 **키의 물리적 위치** 기준으로 저장합니다. 그래서 같은 설정이 세 OS 에서 다르게 눌립니다.

| 설정에 적히는 이름 | Windows · Linux | macOS |
|-------------------|-----------------|-------|
| `ctrl` | Ctrl | Control (⌃) |
| `alt` | Alt | **Command (⌘)** |
| `shift` | Shift | Shift (⇧) |
| `option` | (없음) | Option (⌥) |

macOS 의 ⌘ 는 Windows · Linux 의 Alt 와 같은 자리에 있어서, 설정값 `alt+t` 는 Windows 에서 `Alt+T`, macOS 에서 `Cmd+T` 로 눌립니다. 아래 표는 이 규칙으로 두 열을 적었습니다.

**비라틴 키보드에서도 위치로 맞춥니다.** 러시아어 · 그리스어처럼 라틴 문자가 아닌 배열을 써도 단축키는 키캡의 라틴 위치로 인식됩니다 — 러시아어 배열에서 `H` 자리(러시아어로는 `Р` 가 나오는 키)를 수식키와 함께 누르면 `Ctrl+Shift+H` 단축키가 그대로 동작합니다. 배열을 바꿔도 단축키를 다시 잡을 필요가 없습니다. 마크다운 · 웹 미리보기 화면 위에서도 같습니다.

macOS 에서 설정 화면의 표기를 `⌘` `⌥` `⇧` 심볼로 바꾸려면 **설정** > **일반** <!-- en: General --> > **표시** <!-- en: Display --> 의 **Alt 키 표시** <!-- en: Alt key display --> · **Option 키 표시** <!-- en: Option key display --> · **Shift 키 표시** <!-- en: Shift key display --> 를 바꿉니다. 저장되는 값은 그대로입니다.

## 기본 단축키 (Tasty 프리셋)

처음 설치하면 **Tasty** 프리셋이 적용돼 있습니다. 한 동작에 여러 조합이 있으면 전부 동작합니다.

| 하는 일 | Windows · Linux | macOS |
|---------|-----------------|-------|
| 새 워크스페이스 | `Alt+N` | `Cmd+N` |
| 워크스페이스 닫기 | `Alt+Shift+W` | `Cmd+Shift+W` |
| 워크스페이스 이름 변경 · 부제목 변경 | `F3` · `F4` | `F3` · `F4` |
| n 번 워크스페이스로 | `Alt+1` ~ `Alt+9` | `Cmd+1` ~ `Cmd+9` |
| 다음 · 이전 워크스페이스 | `Alt+J` · `Alt+K` | `Cmd+J` · `Cmd+K` |
| n 번 카테고리로 | `Ctrl+Shift+1` ~ `Ctrl+Shift+0` | `Ctrl+Shift+1` ~ `Ctrl+Shift+0` |
| 다음 · 이전 카테고리 | `Ctrl+Shift+J` · `Ctrl+Shift+K` | `Ctrl+Shift+J` · `Ctrl+Shift+K` |

### 기본값이 비어 있는 동작

다음은 실수 방지를 위해, 또는 OS 단축키와 겹쳐서 기본 조합이 없습니다. 필요하면 직접 지정합니다.

- **종료** <!-- en: Quit --> · **즉시 종료** <!-- en: Immediate quit --> · **백그라운드로 최소화** <!-- en: Minimize to background --> (Mac 프리셋은 `Cmd+Q` · `Cmd+M`, Linux 프리셋은 `Ctrl+Q` 가 들어 있습니다)
- **다음 탭** · **이전 탭** 의 자유 조합 (`Ctrl+Tab` 이 OS 와 겹쳐 비워 둠 — 번호 전환의 `Ctrl+L` · `Ctrl+H` 는 동작합니다)
- **마크다운 열기** · **탐색기 열기** · **마크다운으로 전환** · **탐색기로 전환**
- **워크스페이스 · 탭 · 페인 프리셋 적용**, **카테고리 전체 접기/펴기**
- **윈도우 최소화** · **윈도우 최대화/확대** · **윈도우 닫기**
- 사이드바 **도구** 메뉴의 항목들 — **포트 스캐너 열기** <!-- en: Open port scanner --> · **원격 도구 열기** <!-- en: Open remote tools --> · **프리셋 윈도우 열기** <!-- en: Open preset window --> · **튜토리얼 열기** <!-- en: Open tutorial --> · **파일 피커 열기** <!-- en: Open file picker -->
- Git 뷰어 열기 (플러그인)

## 프리셋

**설정** > **단축키** > **프리셋** <!-- en: Preset --> 에 네 가지가 있습니다. 프리셋은 권장 세트일 뿐 OS 에 강제되지 않습니다 — Windows 에서 Mac 프리셋을 써도 됩니다.

| 프리셋 | 기준 | Tasty 프리셋과 다른 점 |
|--------|------|------------------------|
| **Tasty** (기본) | 자체 | 위 표. 복사 · 붙여넣기 · 줌은 세 OS 관례를 모두 묶어 둡니다 |
| **Mac** | iTerm2 · Terminal.app | `Cmd` 중심. 설정 `Cmd+,` · 알림 `Cmd+Shift+I` · 사이드바 `Cmd+Shift+B` / `Cmd+B` · 명령 팔레트 `Cmd+Shift+P` · 복사/붙여넣기 `Cmd+C` / `Cmd+V` 만 · 종료 `Cmd+Q` · 백그라운드 `Cmd+M`. **활성 항목 닫기** 와 **워크스페이스 닫기** 는 비어 있고 페인 닫기는 `Cmd+Shift+W` |
| **Windows** | Windows Terminal | 페인 분할 `Alt+Shift+E` / `Alt+Shift+D`, 서피스 분할 `Alt+D` / `Alt+E` · 새 윈도우 `Ctrl+Shift+N` · 복사/붙여넣기 `Ctrl+C` / `Ctrl+V` 만 |
| **Linux** | GNOME Terminal | Windows 프리셋과 같되 복사/붙여넣기/잘라내기 `Ctrl+Shift+C` / `Ctrl+Shift+V` / `Ctrl+Shift+X` · 종료 `Ctrl+Q` |

적용 절차:

1. **설정** > **단축키** > **프리셋** 목록에서 프리셋 행을 클릭합니다. 지금 쓰는 프리셋에는 **Active** 표시가 붙어 있습니다.
2. 상세 화면의 **기능** <!-- en: Action --> / **현재** <!-- en: Current --> / 프리셋 열 3단 표에서 바뀌는 행을 확인합니다.
3. 오른쪽 위 **적용** <!-- en: Apply --> 을 누릅니다. 아직 파일에는 저장되지 않습니다.
4. 윈도우 아래 **저장** <!-- en: Save --> 을 누릅니다.

프리셋을 적용하면 직접 고쳐 둔 단축키는 모두 프리셋 값으로 돌아갑니다.

## 다른 컴퓨터로 옮기기 — 가져오기 / 내보내기

**설정** > **단축키** 왼쪽 목록 맨 아래(구분선 아래)의 **가져오기 / 내보내기** <!-- en: Import / Export --> 에서 단축키 구성 전체를 파일 한 장으로 옮깁니다. 일반 단축키 · 번호 전환 규칙 · 스크립트 단축키 · 플러그인 단축키가 모두 들어갑니다.

내보내기:

1. **내보내기…** <!-- en: Export… --> 를 누릅니다.
2. 저장할 폴더를 고르고 아래 **파일 이름** <!-- en: File name --> 칸에 이름을 정한 뒤 **저장** 을 누릅니다. 기본 이름은 `tasty-keybindings-<날짜>.toml` 입니다. 목록에서 기존 파일을 누르면 그 이름이 칸에 들어가고, 이미 있는 이름이면 경고가 뜨며 버튼이 **덮어쓰기** <!-- en: Overwrite --> 로 바뀝니다.
3. 저장되면 알림에 파일 경로가 뜹니다. 아직 저장하지 않은 편집도 함께 들어갑니다.

저장하지 못하면(예: 읽기 전용 폴더) **내보내기** 행 안에 **내보내기 파일을 쓰지 못했습니다** <!-- en: The export wasn't written --> 가 뜹니다. **다시 시도** <!-- en: Try again --> 로 같은 자리에 다시 쓰거나 **다른 위치 고르기…** <!-- en: Choose another location… --> 로 다른 곳을 고릅니다. 이 안내가 떠 있는 동안 **내보내기…** 버튼은 눌리지 않습니다. 안내문 가운데 문장은 폴더가 읽기 전용일 때 · 쓸 권한이 없을 때 · 디스크가 가득 찼을 때를 각각 다르게 말해 줍니다. 그 셋 중 어느 것도 아니면 "쓰기가 끝나지 않았습니다" 로 적고, 운영체제가 낸 원문을 그 아래 작은 회색 줄로 덧붙입니다(길면 잘리고, 마우스를 올리면 전문이 보입니다).

가져오기:

1. **가져오기…** <!-- en: Import… --> 를 누르고 옮겨 온 파일을 엽니다. 바로 적용되지 않고 비교 화면이 뜹니다.
2. **일반 바인딩** <!-- en: General bindings --> · **빠른 전환** <!-- en: Quick switch --> · **스크립트 바인딩** <!-- en: Script bindings --> · **플러그인 재지정** <!-- en: Plugin overrides --> 네 묶음으로 현재 값과 가져올 값이 나란히 보입니다. 처음에는 바뀌는 행만 보이고, 오른쪽 위 **전체 N개 보기** <!-- en: Show all N --> 로 전부 볼 수 있습니다.
3. 가져오지 않을 행은 왼쪽 체크를 풉니다. 묶음 제목의 체크는 그 묶음 전체를 켜고 끕니다.
4. 오른쪽 위 **적용** <!-- en: Apply --> 을 누릅니다. 아직 파일에는 저장되지 않습니다.
5. 윈도우 아래 **저장** 을 누릅니다. **취소** 하면 가져온 내용도 전부 버려집니다.

알아 둘 점:

- 빠른 전환은 축(탭 · 워크스페이스 · 카테고리) 단위로 옮겨집니다 — 수식키와 슬롯 키가 함께 움직입니다.
- 이 컴퓨터에만 있는 플러그인 단축키는 파일에 없어도 지워지지 않습니다. 반대로 이 컴퓨터에 설치되지 않은 플러그인의 단축키는 가져오지 않고, 그 사실이 비교 화면에 한 줄로 표시됩니다.
- 파일을 읽으면서 건너뛴 부분이 있으면(더 새 버전의 tasty 가 쓴 파일, 이 버전이 모르는 동작 등) 비교 화면 위에 **경고와 함께 읽었습니다** <!-- en: Read with warnings --> 상자에 한 줄씩 모여 표시됩니다. 네 줄 이상이면 세 줄만 보이고 나머지는 **N개 더 보기** <!-- en: Show N more --> 로 펼칩니다.
- 단축키 파일이 아닌 것을 고르면 비교 화면 대신 **이 파일은 단축키로 읽을 수 없습니다** <!-- en: This file can't be read as keybindings --> 가 뜨고 아무것도 바뀌지 않습니다. **다른 파일 고르기** <!-- en: Choose another file --> 로 다시 고릅니다.

### Mac 에서 만든 파일을 Windows · Linux 로 가져올 때

Mac 의 `Option` 키가 든 단축키는 Windows · Linux 에서 절대 동작하지 않습니다. 그런 단축키가 있으면 비교 화면 위에 **option 바인딩에 대체 조합이 필요합니다** <!-- en: Option bindings need a replacement --> 카드가 뜨고, 모두 정하기 전에는 **적용** 이 눌리지 않습니다.

- 일반 단축키 자리 — 오른쪽 칸을 클릭하고 대신 쓸 조합을 누릅니다. 이 컴퓨터에서 쓰지 않으려면 **비워 두기** <!-- en: Leave unbound --> 를 누릅니다.
- 번호 전환 수식키 자리 — 드롭다운(처음에는 **modifier 선택** <!-- en: Select a modifier --> 으로 비어 있습니다)에서 대신 쓸 수식키 조합을 고릅니다. 수식키는 비워 둘 수 없습니다.
- 정한 조합이 파일 안의 다른 동작과 겹치면 그 행 아래에 표시되고(겹친 행이 둘 이상이면 카드 위쪽에 **충돌 N건** 이 먼저 보입니다), **적용** 할 때 **단축키 중복** 팝업이 뜹니다. **덮어쓰기** 를 고르면 겹친 다른 동작 쪽이 비워집니다.

## 단축키 하나 바꾸기

1. **설정**(`Ctrl+,`) > **단축키** 를 엽니다. 왼쪽 서브탭은 동작의 대상별로 나뉩니다 — **일반** · **워크스페이스** · **페인** <!-- en: Pane --> · **탭** · **서피스** · **클립보드** · **줌** · **탐색기** · **스크립트 실행** <!-- en: Run Scripts --> · **프리셋** · **플러그인** · **가져오기 / 내보내기**.
2. 바꿀 동작의 키 버튼을 클릭하면 **키 조합을 누르세요...** <!-- en: Press key combination... --> 로 바뀝니다. 원하는 조합을 누릅니다.
3. 같은 동작에 조합을 하나 더 두려면 **바인딩 추가** <!-- en: Add binding --> 를 누릅니다.
4. 녹화 중 `Esc` 를 누르면 그 슬롯이 비워집니다.
5. 이미 다른 동작이 쓰는 조합이면 **단축키 중복** <!-- en: Shortcut already in use --> 팝업이 뜹니다. **덮어쓰기** <!-- en: Overwrite --> 를 고르면 기존 동작의 조합이 지워지고 이 동작으로 옮겨집니다.
6. **저장** 을 누릅니다. **취소** <!-- en: Cancel --> 하면 전부 버려집니다.

녹화 규칙:

- 글자 · 숫자 · 스페이스 같은 타이핑 키는 수식키(Ctrl/Alt/Shift) 하나 이상과 함께 눌러야 등록됩니다. `W` 단독은 무시됩니다.
- `F1`~`F12` · `Tab` · `Enter` 같은 키는 수식키 없이도 등록됩니다.
- `Esc` 는 "슬롯 비우기" 로 예약돼 있어 단축키로 녹화할 수 없습니다. `Esc` 가 기본값인 **전체화면 무대 종료** 를 되돌리려면 프리셋을 다시 적용합니다.
- 플러그인 단축키(**플러그인** 서브탭)가 본체 단축키와 겹치면 **플러그인 쪽이 먼저** 동작합니다.

## 번호 전환 규칙 바꾸기

탭 · 워크스페이스 · 카테고리의 "n 번으로" · "다음/이전" 은 **수식키 하나 + 키 하나** 규칙으로 묶여 있습니다. **탭** 서브탭 아래쪽과 **워크스페이스** 서브탭 아래쪽에서 바꿉니다.

- **탭 전환 수식키** <!-- en: Tab switch modifier --> · **워크스페이스 전환 수식키** · **카테고리 전환 수식키** 드롭다운 — 기본 `Ctrl` · `Alt` · `Ctrl+Shift`. 바꾸면 그 축의 슬롯(탭 10 · 워크스페이스 9 · 카테고리 10)이 한꺼번에 바뀝니다.
- **1번 탭:** ~ **10번 탭:** 등 슬롯 버튼 — 수식키 없이 키 하나만 누릅니다(**키 하나만 누르세요 (수식키 없이)...** <!-- en: Press a key (no modifier)... -->). 예를 들어 1번 슬롯을 `Q` 로 바꾸면 `Ctrl+Q` 가 1번 탭이 되고, 수식키를 누르고 있을 때 탭에 뜨는 번호 표시도 `Q` 로 바뀝니다.
- **다음 탭:** · **이전 탭:** 등 — 마찬가지로 키 하나. 기본은 vi 식 `L`/`H`(탭), `J`/`K`(워크스페이스 · 카테고리).
- 드롭다운에서 **개별 지정** <!-- en: Custom --> 을 고르면 공통 수식키 대신 슬롯마다 다른 조합(`Ctrl+Alt+1` 같은)을 녹화합니다. 이때는 번호 표시가 뜨지 않습니다. 다시 규칙 방식으로 돌아가면 그 축은 기본값으로 초기화됩니다.

<a id="팝업에-포커스가-가-있으면-단축키가-안-먹습니다"></a>

## 팝업에 입력하는 동안의 단축키

검색 바 · 파일 선택 · 명령 팔레트처럼 입력을 받는 팝업에 **포커스가 가 있는 동안에는 단축키가
동작하지 않습니다.** 검색어를 입력하는 중에 `Alt+W` 같은 키로 서피스가 닫히는 일을 막기 위한 동작입니다. 팝업이 떠 있기만 하고 포커스가 없으면 단축키는 평소대로 동작합니다.

터미널 조작으로 돌아가려면 다음 중 하나를 사용하세요.

- **`Esc`** — 포커스된 팝업을 놓습니다. 바깥을 클릭했을 때 닫히는 종류면 함께 닫히고,
  그렇지 않은 팝업은 열린 채로 포커스만 풀립니다. 열려 있어도 포커스가 없는 다른 팝업은
  그대로 남습니다.
- **팝업 바깥을 클릭** — `Esc` 와 같은 결과입니다.

설정 윈도우나 알림 패널이 떠 있을 때는 `Esc` 가 그쪽을 먼저 닫습니다.

## 단축키를 외우지 않아도 되는 두 가지

- **수정자 키 힌트** — `Ctrl` · `Alt` · `Shift` 등을 0.5초 이상 누르고 있으면(Shift 단독은 1.2초) 사이드바 아래에 그 조합으로 시작하는 단축키 목록이 뜹니다. 손을 떼면 사라집니다. **설정** > **일반** > **접근성** <!-- en: Accessibility --> > **수정자 키 힌트 표시** <!-- en: Show modifier key hints --> 로 끌 수 있고, 패널은 드래그로 옮기거나 크기를 바꿀 수 있습니다.
- **명령 팔레트** — `Ctrl+Shift+P` 또는 상태바 오른쪽의 팔레트 단축키 키캡. 동작 이름을 타이핑해 `Enter` 로 실행합니다. 단축키 탭에 있는 모든 동작과 활성 플러그인의 전역 명령이 검색됩니다.

## 설정 파일에서 직접 고치기

`~/.tasty/config.toml` 의 `[keybindings]` 절에 저장됩니다. 값은 OS 와 무관한 이름이라 파일을 다른 OS 로 옮겨도 그대로 쓸 수 있습니다.

```toml
[keybindings]
new_tab = ["alt+t"]
copy = ["ctrl+c", "alt+c", "ctrl+shift+c"]
quit = []                      # 비우면 단축키 없음
tab_switch_modifier = "ctrl"   # "ctrl+shift" 처럼 조합도 됨
tab_switch_slot_keys = ["1", "2", "3", "4", "5", "6", "7", "8", "9", "0"]
tab_switch_next_key = "l"
tab_switch_prev_key = "h"
```

`+` 키 자체는 `ctrl++` 또는 `ctrl+plus`, `-` 는 `ctrl+-` 또는 `ctrl+minus`, `=` 는 `ctrl+=` 또는 `ctrl+equals` 로 적습니다. 파일 편집 전반은 [설정](settings.md).
